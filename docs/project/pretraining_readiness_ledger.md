# Protein–molecule platform pretraining-readiness ledger

This ledger coordinates the 2026-08-04 protein-agnostic platform expansion.
It is intentionally separate from the historical Menin and PK/hERG release
surfaces. Substantive large-model training is prohibited during this program.

## Coordination rules

- `/root` is the lead integrator. It owns cross-workstream architecture,
  shared configuration and CLI integration, conflict resolution, complete test
  execution, final artifact verification, and final readiness sign-off.
- Workstreams have exclusive file ownership. An agent must ask the lead before
  editing a file outside its allocation.
- Raw source artifacts are immutable. Generated artifacts must carry source,
  configuration, software, and build lineage.
- Experimental observations, curated labels, and computational predictions
  remain different entity types.
- No workstream may launch substantive large-model pretraining or fine-tuning.
  Tiny smoke tests are permitted only to validate data loading and training
  interfaces, and their metrics are not scientific results.
- Each workstream must report files changed, commands run, tests performed,
  unresolved issues, assumptions, and handoff requirements.
