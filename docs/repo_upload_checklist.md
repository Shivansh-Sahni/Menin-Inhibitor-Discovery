# GitHub Upload Checklist

Before sharing the repository:

- Confirm whether raw public data files should be committed or regenerated by users.
- Confirm whether model pickle files should be committed. They are small, but reproducible from the scripts.
- Check that no internal or private lab data are present.
- Run `python3 scripts/run_pipeline.py --stage report --skip-network`.
- Run tests with `python3 -m pytest` after installing `pytest`, or use the direct curation checks if pytest is unavailable.
- Link reviewers to `reports/summary.md` first.

Suggested repository description:

> Public-data curation and baseline ML workflow for Menin/MEN1 inhibitor activity, hERG liability, and PK/ADMET observations.

Suggested first GitHub issue:

> Add internal Wang lab Menin assay data to the measurement schema and compare scaffold-split baseline performance against public-only models.
