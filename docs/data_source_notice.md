# Data Source Notice

This repository contains public data downloaded from ChEMBL, BindingDB, and PubChem BioAssay.

The code in this repository does not relicense third-party data. Raw and processed data should be used under the terms and citation expectations of the original data providers.

Recommended citations/acknowledgements for downstream work:

- ChEMBL for target activity and hERG/KCNH2 bioactivity records.
- BindingDB for Menin and Menin/KMT2A target-index activity exports.
- PubChem BioAssay for assay metadata and assay data tables.

If internal lab data are added later, keep them outside public commits unless the lab explicitly approves release.
