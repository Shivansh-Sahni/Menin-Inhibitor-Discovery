# Pre-HPC execution contracts

These files specify future work only. No molecular features, protein features, conformers, docking poses, checkpoints, or expensive model runs were created here.

- `FUTURE_FEATURE_CONTRACT.md` / `future_feature_contract.json`: exact feature schema, provenance, missingness, leakage, and aggregation rules.
- `competitor_reproduction_readiness.csv` / `.json`: artifact readiness for the 15 audited systems/methods.
- `HPC_EXECUTION_PLAN.md` / `hpc_execution_plan.json`: staged jobs, storage/checkpoint/retry/determinism policy, and explicitly estimated resources.
- `smoke_test_spec.json`: non-expensive 10–100-molecule acceptance test; not executed.
- `validate_contracts.py`: standard-library structural validation.

Status date: 2026-08-07.
